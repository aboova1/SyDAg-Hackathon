# Field Scout project rules

- Keep source data, plot records, images, model runs, and slide files out of Git.
- Use only information available by the decision date.
- Keep all plots from one site, experiment, and trial block in the same split.
- Select each model with validation data. Report test data only after selection.
- Name the season, sites, plot count, split count, crew capacity, and units with each score.
- Treat low yield as a reason for a field check. Do not claim a crop-stress diagnosis.
- Keep scouting recall and yield error as separate checks.
- State that the 20% visit limit is a team pilot choice.
- State that 2022 block results do not prove future-season field value.
